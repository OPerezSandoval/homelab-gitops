# Rexi Reports

Turns raw platform exports into hourly reports. Source: [OPerezSandoval/rexi-reports](https://github.com/OPerezSandoval/rexi-reports).

Two containers, ported straight from the app's `docker-compose.yml`:

| Workload | Image | Port | Role |
| --- | --- | --- | --- |
| `frontend` | `operez11/rexi-reports-frontend` | 80 | static UI on nginx, reverse-proxies `/api/` |
| `backend` | `operez11/rexi-reports-backend` | 8000 | FastAPI + pandas, generates the workbooks |

Only `frontend` is exposed. The backend has no Ingress and no tunnel route — it is
reachable only from the frontend pod, through nginx's `/api/` rule.

## Two things that will bite you

**`backend` is the required Service name.** The frontend image bakes in
`proxy_pass http://backend:8000`. Rename that Service and the UI 502s on every
upload until the image is rebuilt.

**`backend` must stay at one replica.** Download tokens live in a dict in the
uvicorn process. Two replicas means roughly half of all downloads 404 against a
pod that never saw the token. Fix the token store before scaling.

Both Applications are generated by the `workloads-{dev,prod}` ApplicationSets from
the overlay folder name — there is no `app.yaml`.

## Public exposure — done in the Cloudflare dashboard, not here

The tunnel is token-authenticated (`kubernetes/infra/cloudflare/base/deployment.yaml`),
so its routing table lives in Cloudflare and cannot be committed. Per environment:

1. **Zero Trust → Networks → Tunnels →** the homelab tunnel **→ Public Hostname → Add.**
   - Subdomain `rexireports` (or `dev.rexireports`), domain `archeflow.com`
   - Type `HTTP`, URL `frontend.rexireports-prod.svc.cluster.local:80`
     (dev: `frontend.rexireports-dev.svc.cluster.local:80`)

   Cloudflare creates the proxied DNS record itself. Nothing to add in the DNS tab.

2. **Zero Trust → Access → Applications → Add → Self-hosted**, matching the same
   hostname, with an Allow policy scoped to your own email. **Do this in the same
   sitting as step 1.**

   The app ships no authentication of its own (`README.md`, "Notes"), and every
   route is an unauthenticated file upload that runs pandas on the single Talos
   node that also runs medtracker prod. Between step 1 and step 2 the upload
   endpoint is open to the internet.

3. Raise **Settings → Network → Maximum upload size** if you need the full 64 MB
   the app's nginx allows; Cloudflare's default free-plan body limit is 100 MB, so
   this usually needs no change.

## Verifying without touching the public hostname

The tailnet Ingress is live as soon as ArgoCD syncs, so the whole stack can be
checked before any DNS exists:

```bash
curl -sf https://rexireports-dev.balinese-pentatonic.ts.net/index.html >/dev/null && echo ui ok
curl -sf https://rexireports-dev.balinese-pentatonic.ts.net/api/health && echo api ok
```

The second one proves the nginx → `backend` Service hop, which is the only part
of the compose → Kubernetes port that is not mechanical.

## Follow-ups not done here

- Frontend runs stock `nginx:alpine` as root with a writable root filesystem, same
  as archeflow-site. Moving to `nginx-unprivileged` on :8080 is a change to the app
  repo's Dockerfile.
- Chart.js loads from `cdnjs.cloudflare.com`, so the UI needs outbound internet
  even though it is self-hosted.
